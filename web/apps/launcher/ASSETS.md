# Launcher asset provenance

- `src/assets/bakerrang-logo.png` is an unchanged copy of the canonical `web/brand/bakerrang-logo.png`.
- Launcher favicon, Apple touch, and Android/PWA icons in `public/` are unchanged copies of the tightly trimmed canonical set (originally from the retired `client/public/`); every web app ships the same files.
- Shared Archivo webfonts are documented in `packages/web-tokens/src/fonts/README.md`.
- The WoW Advisor emblem is deliberately the approved neutral placeholder crest. Replace it only after an appropriate World of Warcraft asset is supplied and approved.
