# Archivo webfonts

These WOFF2 files are unchanged copies from the official [Omnibus-Type/Archivo](https://github.com/Omnibus-Type/Archivo) repository (`fonts/webfonts`, `master`) and are distributed under the included SIL Open Font License 1.1.

The BakerRang consumer design system uses Archivo 400–700 for body/UI work and the separate Archivo Expanded 600–800 family for signage, product names, and display typography.
